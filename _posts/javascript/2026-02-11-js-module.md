## JavaScript 모듈화란?

단일 파일의 JS 코드를 여러 파일로 분리해서 사용하면 여러 곳에서 사용할 수 있도록 만드는 거라고 보면 된다.

그런데 이전에는 함수 또는 클레스를 별도의 파일로 분리해서 사용한 거라면 **ECMA6**이 되면서 `import`와 `export` 구문을 이용하게 되었다.

## 기본 사용방법

```javascript
import { sum } from './utils.js';

const res = sum(5, 2);
console.log(res);
```
{: data-label="main.js"}

```javascript
export function sum(a, b) {
	return a + b;
}
```
{: data-label="utils.js"}

모듈을 만들었다면 HTML 파일에서 다음과 같이 작성합니다.

```html
<script type="module" src="main.js"></script>
<script type="module" src="utils.js"></script>
```

### 모듈 가져오기

모듈 파일에서 `export` 된 변수, 함수, 클레스 등이 여러개인 경우 모두 선언해서 가져오려면 불편하다. 따라서 다음과 같이 사용한다.

```javascript
// import { sum, multiple } from './maths.js';
import * as maths from './maths.js';

const res = maths.sum(5, 2);
console.log(res);
const res2 = maths.multiple(5, 2);
console.log(res2);
```
{: data-label="main.js"}

### 모듈 내보내기

모듈 파일에서 여러 변수, 함수, 클레스를 선언할 때 매번 `export`를 붙이기 어려울 수 있는데 다음과 같이 선언하면 된다.

```javascript
function sum(a, b) {
	return a + b;
}
function multiple(a, b) {
	return a * b;
}
export { sum, multiple };
```
{: data-label="maths.js"}

**`default` 사용하기**

지금까지 배운 `export` 구문에서는 지정한 이름으로 가져와야 한다. 예를 들어 `sum` 함수를 내보내면 `sum`으로 가져와야 했다.
하지만 `default`를 쓰면 원하는 이름으로 가져와서 사용할 수 있다.

```javascript
// maths.js
export default const sum = (a, b) => a + b;

// main.js
import { add_score } from './maths.js';

const a = 5;
const b = 15;
const total = add_score(a, b);
console.log(total);
```

## 클레스 나누기

하나의 클레스를 작성하는데 코드가 많아져서 이걸 모듈화하고 싶었다.
매인 클레스의 `this` 값을 모듈의 클레스로 전달한 뒤 모듈에서 매인 클레스의 값을 변경하는 방법이다.

**1. 매인 클레스**

```javascript
import { SubModule } from './subModule.js';

class MainApp {
	constructor() {
		this.status = 'BASIC';
		this.data = 0;
		// 모듈 생성 시 'this'(MainApp 인스턴스)를 전달
		this.module = new SubModule(this);
	}
	run() {
		console.log('before:', this.status, this.data);
		this.module.update(); // 모듈 내 메서드 호출
		console.log('after:', this.status, this.data);
	}
}

const app = new MainApp();
app.run();
// 출력:
// before: BASIC 0
// after: MODULE 100
```
{: data-label="app.js"}

**2. 모듈 클레스

> 원하는 파일명으로 수정하면 된다.
{: .notice--warning}

```javascript
export class SubModule {
	constructor(parent_instance) {
		// 메인 클래스의 인스턴스를 저장
		this.main = parent_instance;
	}
	update() {
		// 메인 클래스의 값 직접 변경
		this.main.status = 'MODULE';
		this.main.data = 100;
	}
}
```
{: data-label="submodule.js"}

> 내가 원한 방식은 모듈 내 클레스로 `this` 값을 전달하면 상속을 받아 매인 클레스에서 선언한 것처럼 사용하는 방식이였으나 그렇게 하려니 좀 복잡하다.
> 1. `this` 값을 전달받아 모듈의 인스턴스에 할당.
> 2. `extends`로 상속 받기: 매인 클레스를 `export`로 선언한 다음 모듈에서 매인 클레스를 상속 받는 방식
> 두번째 방식으로 할 경우 테스트해보지는 않았지만 매인과 모듈이 서로 참조를 하기 때문에 문제가 발생할 것 같다.  
> 그래서 기능별로 모듈화한 다음 매인 클레스에서 불러와 이용하는 방식으로 만들었다.
{: .notice--warning}
