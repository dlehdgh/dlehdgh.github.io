## 자바스크립트(JavaScript)란?

자바스크립트는 클라이언트 환경에서 동작하는 프로그래밍 언어로 쉽게 말해서 우리가 사용하는 브라우저 상에서 동작하는 프로그램이라고 생각하시면 됩니다.

먼저 자바스크립트를 배우기 전에 **HTML**과 **CSS**는 알고 있어야 자바스크립트를 활용할 수 있습니다.

## 변수 선언

**JavaScript**는 변수 선언 시 **데이터 타입**을 지정하지 않아도 되요.
이걸 적는 이유는 다른 프로그레밍 언어을 공부하시던 분들은 데이터 타입을 선언해야 하는 줄 알고 계실 것 같아서 에요.

변수를 선언하는 방법은 다움과 같아요.

```javascript
var 변수명 = 값;
let 변수명 = 값;
const 변수명 = 값;
```

예전에는 `var`로 선언했었는데 **ES6(ECMAScript 6)**으로 오면서 `let`과 `const`를 사용하기 시작한 것 같아요.

- `var` : 전역 변수로 재할당 가능
- `let` : 지역 변수로 재할당 가능
- `const`: 고정 값으로 재할당 불가능

`let`로 선언하면 **지역 변수**로 해당 블록 내에서만 사용 가능합니다. 블록은 중괄호로 감싸진 영역이라고 할 수 있어요. 예제를 보면 이해하기 쉬울 거에요.

```javascript
for (var i=0; i<5; i++) {
	console.log(i + '번');
}
console.log('루프가 끝난 후:', i);
for (let j=0; j<5; j+++ {
	console.log(j + '번');
}
console.log('루프가 끝난 후:', j);
```

`var`로 선언한 `i` 변수는 `for` 문이 끝났어도 정상적으로 출력이 되지만, 
`let`로 선언한 `j` 변수는 `for` 문이 끝나면 사용할 수 없어서 `ReferenceError: j is not defined`라는 오류가 발생해요.

`const`로 선언하면 어떻게 되는지 예제를 작성해 볼게요.

```javascript
const name = '홍길동';
name = '크리스';
consle.log('name:', name);
const args = [1, 5, 8, 12];
args[0] = 9;
consle.log('args:', args);
const fruit_color = { apple: 'red', banana: 'yelow'};
fruit_color.apple = 'green';
consle.log('fruit_color:', fruit_color);
```

위 코드를 **콘솔창**에서 한 줄씩 실행을 해보면 `name` 변수를 변경하는 코드에서만 `Uncaught TypeError: Assignment to constant variable.` 오류가 발생하는 걸 확인할 수 있어요.
그런데 배열 또는 객체를 변경하는 코드는 정상적으로 동작해요.
따라서 `const`로 선언한다고 해서 변수 값이 완전히 고정되는 건 아니에요.

## 데이터 타입

- `number` : 숫자형
- `string` : 문자열
- `boolean` : 논리형
- `null` : 의도적으로 **값이 없음**을 명시
- `undefined` : 값이 할당되지 않은 상태.
- `symbol` (ES6에서 추가됨) : 주로 이름의 충돌 위험이 없는 **유일한 객체의 Property Key**를 만들기 위해 사용한다.

변수를 선언한 뒤 `typeof` 함수로 실행해보시면 데이터 타입을 확인할 수 있어요.

```javascript
let name = '홍길동';
let age = 12;
console.log('name:', typeof name)
console.log('age:', typeof(age));
// 출력
// name: string
// age: number
```

`typeof` 함수는 보통 값을 전달 받을 때 **데이터 타입**을 확인하는 용도로 많이 사용해요.
