JavaScript로 게임을 만들 때 예전에는 HTML 요소를 추가해서 게임을 구성했지만, 요즘에는 **캔버스(Canvas)**에 그리는 방식으로 만들어요.

그런데 캔버스를 활용할 경우 스크린리더로 접근할 수 없어서 접근성이 좋지가 않아요.

## 캔버스 생성하기

```html
<canvas id="myCanvas"></canvas>
```

```javascript
// const canvas = document.getElementById("myCanvas");
const canvas = document.querySelector("#myCanvas");
const ctx = canvas.getContext("2d");

// 크기 지정
canvas.width = 400;
canvas.height = 400;
```

위 코드를 한 번 선언해둔 다음 `ctx` 변수를 가지고 그리는 거에요.

## 텍스트 그리기

텍스트를 그리는 경우 왼쪽 위를 기준으로 하는게 아니라 정중앙 위치를 기준으로 하기 때문에 잘 계산하셔야 돼요.

```javascript
// 폰트 및 스타일 설정
ctx.font = 'bold 30px Arial';
ctx.fillStyle = 'blue'; // 채우기 색상
ctx.strokeStyle = 'black'; // 외곽선 색상
// 텍스트 그리기
// fillText(텍스트, x좌표, y좌표)
ctx.fillText('안녕!', 50, 50);
// 외곽선만 그리기
ctx.strokeText('캔버스', 50, 100);
```

- `font`: 폰트 스타일, 굵기, 크기, 서체(예: `'italic bold 24px serif'`)
- `textAlign`: 텍스트 가로 정렬(`start`, `end`, `left`, `right`, `center`)
- `textBaseline`: 텍스트 세로 기준선(`top`, `middle`, `bottom`, `alphabetic` 등)
- `direction`: 텍스트 작성 방향(`ltr`, `rtl`)
- `fillText`: 지정한 좌표에 텍스트 그리기
- `strokeText`: 지정한 좌표에 텍스트를 윤곽선만 그리기

## 사각형 그리기

```javascript
ctx.fillStyle = "rgb(255,0,0)";
ctx.fillRect(10, 10, 50, 50);
ctx.strokeStyle = "#ffff00"
ctx.strokeRect(50, 50, 50, 50);
```

- `fillRect(x, y, width, height)`: 색칠된 직사각형 그리기
- `strokeRect(x, y, width, height)`: 직사각형 윤곽선을 그리기
- `clearRect(x, y, width, height)`: 특정 부분을 지우는 직사각형 그리기

> `fillStyle` 또는 `strokeStyle`로 한 번 색상을 지정해 놓으면 그 다음부터 그리는 모든 도형에 색상이 적용됩니다.

## 삼각형 그리기

캔버스에서 **경로(Path)**는 선, 곡선 등을 이용해 복잡한 도형이나 그림을 그리는 핵심 기능입니다.

**경로(Path)**를 이용해서 삼각형과 오각형 등의 다각형을 그릴 수 있어요. 이번에는 삼각형을 그려 볼 거에요.

```javascript
ctx.beginPath();
ctx.moveTo(75, 50);
ctx.lineTo(100, 75);
ctx.lineTo(100, 25);
ctx.fill();
ctx.stroke();
ctx.closePath();
```

- `beginPath()`: 새로운 경로를 생성하는 것이다. 즉 도형을 하나로 묶는 거라고 보면 된다.
- `moveTo(x, y)`: 시작 좌표를 이동하는 것이다.
- `lineTo(x, y)`: 지정한 좌표까지 선을 그리는 것이다.

## 원 그리기

```javascript
ctx.beginPath();
ctx.arc(10, 10, 50, 0, 2 * Math.PI);
ctx.fillStyle = 'blue';
ctx.fill();
ctx.stroke();
```

원은 `arc(중심X, 중심Y, 반지름, 시작각도, 종료각도)`로 그리면 된다.

## 이미지 그리기

가장 기본적인 형태로, 이미지를 그리려면 `ctx.drawImage(이미지객체, x좌표, y좌표, 너비, 높이)`를 사용하면 돼요.
만약 원본 크기 그대로 표시하려면 너비와 높이를 생략하면 돼요.

```javascript
const img = new Image();
img.src = 'apple.png'; // 이미지 경로 설정

// 이미지가 로드된 후 캔버스에 그리기
img.onload = function() {
	ctx.drawImage(img, 0, 0); 
};
```

**이미지 일부분만 잘라서 그리기**

게임을 만들 때 사용할 이미지를 찾다 보면 **스프라이트 이미지**라고 여러 이미지를 하나의 파일로 합쳐 놓은게 있어요.
스프라이트 이미지를 사용할 때 원하는 부분만 자르는 방법은 다음과 같아요.

```javascript
const sprite_img = new Image();
sprite_img.src = 'sprite.png';
sprite_img.onload = function() {
	ctx.drawImage(sprite_img, 50, 50, 100, 100, 0, 0, 200, 200);
};
```

캔버스에 이미지를 그릴 때 모든 이미지 파일을 미리 불러온 다음 사용 시 이미지를 그리는게 좋아요.

## 애니메이션 만들기

캔버스로 애니메이션을 만드는 방법은 다음과 같아요.
1. 캔버스 초기화
1. 캐릭터 그리기
1. 캐릭터 움직이기

애니메이션을 만들 때 캔버스에 한 번 그리고 위치를 변경한 후 다시 그리게 되면 기존에 그린게 남아 있으므로 지워주고 다시 그려줘야 해요.

여기서 중요한게 매번 다시 그려야 하는데 HTML 요소처럼 현재 위치를 가져올 수 없으니 캐릭터의 위치, 크기 등의 정보를 변수에 저장해야 돼요.

간단하게 사각형 블럭이 왼쪽에서 오른쪽으로 이동하는 애니메이션을 만들어 볼게요.

```javascript
const canvas = document.querySelector("#myCanvas");
const ctx = canvas.getContext("2d");
const WIDTH = 800;
const HEIGHT = 600;
// 움직일 캐릭터 정보
let char_item = {
	color: 'blue',
	width: 50,
	height: 60,
	x: 10,
	y: 10
};

function render() {
	ctx.clearRect(0, 0, WIDTH, HEIGHT);
	// 사각형 그리기
	ctx.fillStyle = char_item.color;
	ctx.fillRect(char_item.x, char_item.y, char_item.width, char_item.height);
	char_item.x += 2;
	// 애니메이션 멈추기
	if (char_item.x + char_item.width > WIDTH) {
		return;
	}
	requestAnimationFrame(render);
}
window.addEventListener('DOMContentLoaded', function (event) {
	canvas.width = WIDTH;
	canvas.height = HEIGHT;
	render();
});
```
