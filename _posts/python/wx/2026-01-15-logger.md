**wxPython**을 사용하기 전에는 `print()` 구문으로 오류 메시지를 출력했는데요.
오류가 발생한 위치를 확인하기 어려우며, 프로그램 실행이 끝난 뒤에는 오류 내용을 다시 확인할 수 없다 보니 불편하더라고요.
그래서 이러한 문제를 해결하기 위해 **로그 파일로 기록을 남기는 방식**을 사용하기로 했어요.

## 로그란?

**로그(Log)**란 프로그램이 실행되는 동안 발생하는 **상태 정보나 오류 내용을 기록으로 남기는 것**을 말합니다.

**로깅(logging)** 패키지를 통해 생성되는 로그 기록에는 **파일명**, **파일 경로**, **함수명**, **라인 번호** 등 로깅 이벤트가 발생한 시점의 상세한 정보가 함께 저장됩니다.
덕분에 프로그램 실행 이후에도 오류 원인을 쉽게 추적하고 진단할 수 있습니다.

또한, 어플리케이션에서 사용하는 **하위 모듈에서 발생한 로그 이벤트에도 일관되게 접근**할 수 있으며,
**로깅 레벨(Level) 설정**을 통해 필요한 로그만 선택적으로 기록하고 필터링할 수 있다는 장점이 있습니다.

이처럼 **로거(Logger)**를 활용하면 어플리케이션의 실행 상태를 체계적으로 기록하고,
문제 상황을 보다 효율적으로 분석할 수 있으므로 적극적으로 사용하는 것이 좋습니다.

## 로그 레벨

로그는 아래 목록 중 하나의 **레벨**을 가지며, 각 레벨의 로그는 각기 다른 용도를 지니고 있다.

- **DEBUG**: 프로그램 작동에 대한 상세한 정보를 가지는 로그. 문제의 원인을 파악할 때에만 이용.
- **INFO**: 프로그램 작동이 예상대로 진행되고 있는지 트래킹하기 위해 사용.
- **WARNING**: 예상치 못한 일이나 추후 발생 가능한 문제를 표시하기 위함.
- **ERROR**: 심각한 문제로 인해 프로그램이 의도한 기능을 수행하지 못하고 있는 상황을 표시.
- **CRITICAL**: 더욱 심각한 문제로 인해 프로그램 실행 자체가 언제라도 중단될 수 있음을 표시.

로거 설정 시 레벨을 지정해 주면 해당 레벨 이상의 (더 심각한 쪽으로) 로그 이벤트만이 기록된다. 디폴트로 설정되는 로그 출력 레벨은 **WARNING**으로, **WARNING** 이상의 심각도를 가지는 이벤트만 트래킹 되도록 세팅된다.

## 로그 포맷

| 어트리뷰트 이름 | 포맷 | 설명 |
|---|---|---|
| **args** | 직접 포맷할 필요 없음 | message를 생성하기 위해 `msg`에 병합되는 인자의 튜플. 또는 (인자가 하나뿐이고 딕셔너리일 때) 병합을 위해 값이 사용되는 딕셔너리 |
| **asctime** | `%(asctime)s` | 사람이 읽을 수 있는 LogRecord 생성 시간. 기본 형식은 `2003-07-08 16:49:45,896` (쉼표 뒤는 밀리초) |
| **created** | `%(created)f` | LogRecord가 생성된 시간 (`time.time()` 반환값) |
| **exc_info** | 직접 포맷할 필요 없음 | 예외 튜플 (`sys.exc_info`에서 제공) 또는 예외가 없을 경우 `None` |
| **filename** | `%(filename)s` | pathname의 파일명 부분 |
| **funcName** | `%(funcName)s` | 로깅 호출을 포함하는 함수 이름 |
| **levelname** | `%(levelname)s` | 메시지의 텍스트 로깅 수준 (`DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`) |
| **levelno** | `%(levelno)s` | 메시지의 숫자 로깅 수준 |
| **lineno** | `%(lineno)d` | 로깅 호출이 발생한 소스 코드의 행 번호 |
| **message** | `%(message)s` | 로그된 메시지. `msg % args`로 계산되며 `Formatter.format()` 호출 시 설정됨 |
| **module** | `%(module)s` | 모듈 이름 (filename의 이름 부분) |
| **msecs** | `%(msecs)d` | LogRecord 생성 시간의 밀리초 부분 |
| **msg** | 직접 포맷할 필요 없음 | 로깅 호출에서 전달된 원본 포맷 문자열. `args`와 병합되어 message 생성 |
| **name** | `%(name)s` | 로깅 호출에 사용된 로거 이름 |
| **pathname** | `%(pathname)s` | 로깅 호출이 발생한 소스 파일의 전체 경로 |
| **process** | `%(process)d` | 프로세스 ID |
| **processName** | `%(processName)s` | 프로세스 이름 |
| **relativeCreated** | `%(relativeCreated)d` | logging 모듈이 로드된 이후 LogRecord가 생성되기까지의 시간 (밀리초) |
| **stack_info** | 직접 포맷할 필요 없음 | 현재 스레드의 스택 정보 (사용 가능한 경우) |
| **thread** | `%(thread)d` | 스레드 ID |
| **threadName** | `%(threadName)s` | 스레드 이름 |

## 로그 남기기

```python
# myapp.py
import logging
import mylib
logger = logging.getLogger(__name__)

def main():
	logging.basicConfig(filename='myapp.log', level=logging.INFO)
	logger.info('Started')
	mylib.do_something()
	logger.info('Finished')

if __name__ == '__main__':
	main()
```

```python
# mylib.py
import logging

```

위 코드에서 `myapp.py`를 실행하면 `myapp.log` 파일이 생성되는데 파일 내용은 다음과 같다.

```bash
INFO:__main__:Started
INFO:mylib:Doing something
INFO:__main__:Finished
```

## 로그 관리 모듈 만들기

처음 로그를 사용하려고 보니 매번 `logger` 변수를 선언해줘야 해서 불편하더라고요. 그래서 모듈로 만들었어요.

```python
# -*- coding: utf-8 -*-
# 로그 기록 관리
# logmanager.py

import os
import sys
import time
import datetime
import logging
import logging.handlers
import threading

class LogManager:
	def __init__(self, log_dir: str, retention_days = 7):
		self.log_dir = log_dir
		self.retention_days = retention_days

		# 로그 파일을 저장할 폴더가 없는 경우 폴더 생성
		if not os.path.exists(self.log_dir):
			os.makedirs(self.log_dir)

		# 로그 파일 이름과 저장 경로 지정
		now = datetime.datetime.now()
		log_filename = now.strftime('%Y-%m-%d_%H%M%S.log')
		log_filepath = os.path.join(self.log_dir, log_filename)

		# 로그 포멧 지정
		formatter = logging.Formatter('[%(asctime)s][%(module)s] %(levelname)s: %(message)s', '%Y-%m-%d %H:%M:%S')
		
		# 로그를 파일에 출력
		file_handler = logging.handlers.TimedRotatingFileHandler(filename=log_filepath, when='midnight', interval=1, encoding='utf-8')
		file_handler.setFormatter(formatter)
		file_handler.suffix = '%Y-%m-%d %H-%M-%S.log'

		# 로그를 콘솔에 출력
		console_formatter = logging.Formatter('%(levelname)s: %(module)s: %(message)s')
		console_handler = logging.StreamHandler()
		console_handler.setFormatter(console_formatter)

		self.logger = logging.getLogger()
		# 레벨 설정
		self.logger.setLevel(logging.INFO)
		self.logger.addHandler(file_handler)
		self.logger.addHandler(console_handler)

		self._start_auto_delete_thread()

	# 로그 파일 자동으로 삭제
	def _start_auto_delete_thread(self):
		# 지정된 경과일수가 지난 파일 삭제
		def delete_old_logs():
			while True:
				now = datetime.datetime.now()
				cutoff_date = now - datetime.timedelta(days=self.retention_days)
				for filename in os.listdir(self.log_dir):
					filepath = os.path.join(self.log_dir, filename)
					if os.path.isfile(filepath):
						file_mtime = datetime.datetime.fromtimestamp(os.path.getmtime(filepath))
						if file_mtime < cutoff_date:
							os.remove(filepath)
							self.logger.info(f'Old log file deleted: {filename}')
				time.sleep(3600)

		self.delete_thread = threading.Thread(target=delete_old_logs, daemon=True)
		self.delete_thread.start()

	# 호출한 함수의 클래스명.함수명 또는 함수명 반환
	def _get_func_name(self):
		'''호출한 함수의 클래스명.함수명 또는 함수명 반환'''
		frame = sys._getframe(2) # log.info() → _log() → 호출자이므로 2단계 위
		func = frame.f_code.co_name # 함수명
		if 'self' in frame.f_locals:
			class_name = frame.f_locals['self'].__class__.__name__
			return f'{class_name}.{func}'
		elif func == '<module>': # 전역(모듈) 스코프에서 호출된 경우
			return '__main__'
		else:
			return func

	# 로그 메시지 출력
	def _log(self, level: int, message: str):
		prefix = self._get_func_name()
		self.logger.log(level, f'{prefix}: {message}')

	# 표준 로깅 메서드
	def debug(self, message: str):
		'''프로그램 작동에 대한 상세한 정보를 가지는 로그'''
		self._log(logging.DEBUG, message)

	def info(self, message: str):
		'''프로그램 작동이 예상대로 진행되고 있는지 트래킹하기 위해 사용'''
		self._log(logging.INFO, message)

	def warning(self, message: str):
		'''예상치 못한 일이나 추후 발생 가능한 문제를 표시하기 위함'''
		self._log(logging.WARNING, message)

	def error(self, message: str):
		'''심각한 문제로 인해 프로그램이 의도한 기능을 수행하지 못하고 있는 상황을 표시'''
		self._log(logging.ERROR, message)

	def critical(self, message: str):
		'''더욱 심각한 문제로 인해 프로그램 실행 자체가 언제라도 중단될 수 있음을 표시'''
		self._log(logging.CRITICAL, message)


log = LogManager('logs')
```
{: data-label="logmanager.py"}

사용 방법은 다음과 같아요.

```python
from logmanger import log
log.info('Hello')
```

현재는 기본값인 **logs** 폴더에 로그 파일이 저장되게 되어 있는데요. 나중에 직접 경로를 설정하려면 `log = LogManger('history')`와 같이 작성을 해주면 되요.
